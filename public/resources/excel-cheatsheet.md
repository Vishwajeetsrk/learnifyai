## Top Formulas
| Formula | What it does |
| --- | --- |
| =SUM(A1:A10) | Adds numbers |
| =AVERAGE(A1:A10) | Mean |
| =MAX() / =MIN() | Highest / lowest |
| =COUNT(A1:A10) | Counts numbers |
| =COUNTA() | Counts non-empty |
| =IF(A1>50,"Pass","Fail") | Condition |
| =VLOOKUP(lookup, table, col, FALSE) | Find values |
| =XLOOKUP() | Modern lookup (Excel 365) |
| =CONCATENATE() / & | Join text |
| =TEXT(value, "format") | Format numbers |
| =NOW() / =TODAY() | Date & time |

## Keyboard Shortcuts
Ctrl+Shift+L → Filters · Ctrl+T → Table · F4 → Repeat / lock reference · Alt+Enter → New line in cell

## Absolute vs Relative
A1 relative · $A$1 absolute (locks column and row)

## Pivot Tables (5 steps)
1. Select data → 2. Insert PivotTable → 3. Drag fields to Rows/Values → 4. Filter/Group → 5. Refresh (right-click → Refresh)

## Charts
Bar / Column for comparisons · Line for trends · Pie for share (max 5 slices)

## Data Cleanup
Remove Duplicates (Data tab) · Text to Columns · Trim Spaces · Conditional Formatting → Highlight rules

## Conditional Formatting
Select range → Home → Conditional Formatting → Color Scales / Data Bars — instant heatmaps.
