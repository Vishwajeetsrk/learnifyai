# ChatGPT & Claude Productivity Cheat Sheet
By Learnify AI — Vishwajeet

## The Golden Formula
Role + Task + Context + Format + Example

```
You are a senior Python instructor.
Explain list comprehensions to a beginner.
Use a real example (prices list → discounts).
End with a practice challenge and its solution.
```

## Prompt Patterns
- Persona: "You are a [role]..."
- Few-shot: give 2 examples of the output you want
- Chain of thought: "Think step by step before answering"
- Constraints: "Max 150 words, bullets only, no jargon"
- Iterate: "Make it shorter" / "Give a beginner version"

## Claude Tips (Claude.ai / Claude Code)
- Use @-mentions to attach files and compare documents
- Projects → add knowledge base so Claude knows your stack
- Artifacts → build and preview small apps/apps in the chat
- Claude Code → edit code in your repo with natural language
- Style: clear, calm, detailed; ask it to "be concise"

## ChatGPT Tips
- Custom instructions (Settings) → pre-train your assistant
- Use images: upload a screenshot and ask for analysis
- GPTs / Projects → save specialized assistants
- Voice mode for on-the-go drafting
- Ask for tables/CSV when you need structured output

## Learning Stack (recommended)
1. ChatGPT for concept explanations & quizzes
2. Claude for code review, docs, and long documents
3. Both → generate practice problems daily (spaced repetition)

## Red Flags
- Never paste secrets/API keys into chat
- Verify code before running (especially destructive commands)
- AI is 80% right — the 20% is your job to check
