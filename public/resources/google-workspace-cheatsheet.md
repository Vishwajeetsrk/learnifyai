# Google Workspace Quick Reference
By Learnify AI — Vishwajeet

## Gmail Pro
- Gmail → Settings → Canned responses (templates)
- "from:me", "has:attachment", "is:unread" search operators
- Keyboard: C compose · E archive · Shift+U mark unread
- Scheduled send → the clock icon next to Send
- Confidential mode → expiry + no forwarding

## Google Docs
- / menu → type "/table", "/heading" to insert anything
- @ mention → add people, dates, files
- Tools → Voice typing (Ctrl+Shift+S)
- Versions: File → Version history
- Compare documents (Tools → Compare)

## Google Sheets
=SUM/AVERAGE/VLOOKUP — same formulas as Excel
- Ctrl+Shift+L filters · Ctrl+Shift+4 currency
- Explore button (bottom right) → auto insights & charts
- Google Apps Script → automate with code

## Google Slides
- Explore → AI-generated layouts
- Ctrl+D duplicate · F5 present
- Insert → Speaker notes; captions during presentation (CC)

## Google Drive
- Shift+Z → add to multiple folders
- Right-click → Get link → set permissions
- Star important files · Shared drives for teams
- Offline access: Settings → Offline

## Google Calendar
- Create event → add video meeting (Meet) automatically
- Find a time / focus time blocks
- Multiple calendars (work/personal) with color coding

## Google Meet
- Present with captions · background blur · breakout rooms
- Pin + spotlight speakers
