# Word & PowerPoint Quick Reference
By Learnify AI — Vishwajeet

## Word — Fast Formatting
- Ctrl+B / I / U → bold / italic / underline
- Ctrl+E / L / R → center / left / right align
- Ctrl+Shift+> / < → bigger / smaller font
- F4 → repeat last action (magic!)
- Ctrl+Enter → page break

## Word — Styles
Use Heading 1/2/3 styles (not manual fonts) → automatic table of contents + navigation pane.

## Word — Tables & Images
Insert → Table; Layout tab → repeat header rows. Images: use "Wrap Text → Square" to move freely.

## Word — Collaboration
Review → Track Changes; Insert → Comments; Share → real-time co-authoring.

## PowerPoint — 10-20-30 Rule
Max 10 slides · 20 minutes · 30pt font minimum.

## PowerPoint — Golden Rules
1. One idea per slide
2. Max 6 words per bullet
3. Use images/icons over text walls
4. Consistent fonts (max 2) + brand colors

## PowerPoint — Shortcuts
Ctrl+M → new slide · F5 → start show · Ctrl+D → duplicate slide/object · Alt+Shift+1..5 → promote/demote

## PowerPoint — Design Helpers
Designer pane (AI layouts) · Morph transition for cinematic slides · Slide Master for global edits (View → Slide Master)

## Export & Share
File → Export → PDF (keep fonts) · OneDrive/SharePoint for real-time sharing.
