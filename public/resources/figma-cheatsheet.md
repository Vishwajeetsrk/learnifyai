# Figma Quick Reference
By Learnify AI — Vishwajeet

## Shortcuts
V Move · F Frame · T Text · R Rectangle · O Ellipse · P Pen · Shift+1 zoom fit · Ctrl+D duplicate · Alt+drag duplicate · Ctrl+G group · Ctrl+Shift+G ungroup

## Auto Layout (the #1 feature)
Select frame → Shift+A → children align in a row/column automatically. Padding, gap, resizing — build UI that reflows like CSS Flexbox.

## Constraints & Resizing
Fixed / Fill / Hug — like CSS width: fixed, 100%, auto.

## Components
Create component (Ctrl+Alt+K) → reuse instances → edit once, updates everywhere. Use Variants for button states (default/hover/disabled).

## Styles
Color, Text, Effect, Grid styles — the Figma version of CSS variables.

## Design Tokens (what pros do)
Name styles by role: text/heading, bg/surface, brand/primary — not by color hex.

## Frames vs Sections
Frame = screen/component. Section = group of screens.

## Plugins worth installing
- Unsplash (images)
- Iconify (icons)
- Figma Tokens (design tokens)
- Stark (accessibility)

## Handoff
Dev Mode → click layer → CSS code → copy → paste in your project.

## Grids
12-column grid + 8pt spacing system — everything aligns to multiples of 8.
